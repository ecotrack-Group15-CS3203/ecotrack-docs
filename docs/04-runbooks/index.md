# Runbooks

Operational guides for developing, deploying, and maintaining the EcoTrack platform.

## In This Section

- **Local Development** — Docker Compose setup, port map, environment variables, seeding
- **AWS Deployment** — EC2, RDS with PostGIS, S3 bucket policy, and GitHub Actions secrets
- **CI/CD Pipeline** — GitHub Actions workflow: lint → test → Docker build → EC2 deploy

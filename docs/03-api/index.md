# API Reference

This section documents all REST API endpoints exposed by the EcoTrack NestJS backend.

## In This Section

- **Authentication** — WSO2 Asgardeo OAuth2 flow, RBAC roles, token format
- **Incidents** — Reporting, retrieving, and updating environmental incident records
- **Organizations** — Tenant registration, invite links, volunteer management
- **Tasks & Events** — Converting incidents to tasks or community cleanup events
- **Workflows** — Dynamic status stage configuration per tenant

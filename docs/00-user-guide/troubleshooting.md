# Troubleshooting

| Problem | What to do |
|---|---|
| "Location access is turned off for EcoTrack" | Tap **Open settings** and allow location for EcoTrack. You can also drag the pin to set the location by hand. |
| Camera won't open | Allow camera access in Android settings, or use **Gallery** instead. |
| "Report pending · waiting for connection" | This is normal when you are offline. The report sends automatically once you reconnect. |
| No Tasks/Events tabs in the app | You aren't a volunteer yet. [Join an organisation](./volunteers#become-a-volunteer) and wait for approval. |
| The website redirects to the "get the app" page after sign-in | Your account isn't an organisation admin. Use an admin account, or [register an organisation](./org-admins#register-an-organisation). |
| "No incidents are at the stage required…" when creating a task or event | Move the incident to the stage named in [Workflow Stage Rules](./org-admins#workflow-stages-and-rules), or change the rule. |
| "Invite link expired / revoked / reached its usage limit" | Ask the organisation for a new invite link. |
